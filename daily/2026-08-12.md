## [Introducing Dogwood: runtime verification for AI agents](https://aws.amazon.com/blogs/opensource/introducing-dogwood-runtime-verification-for-ai-agents/) 🤓

Traditional authorization systems answer "can this agent call this tool now?" — Dogwood answers "can this agent call this tool, given everything it has already done in this session?" by extending Cedar with Metric First-Order Temporal Logic (MFOTL), a formalism from the runtime verification literature, so policies can enforce rate limits over time windows, prerequisite step ordering, and escalation triggers that are structurally impossible to express in stateless policy evaluation. A policy like "allow SendEmail only after VerifyRecipient has been called, and at most three times per 10-minute window" is a single Dogwood rule; in plain Cedar it would require a bespoke side channel to track session history. Dogwood is open source (Apache 2.0), composes with existing Cedar policies without migration, and is integrated into Amazon Bedrock AgentCore Policy. Published August 6, 2026. #ai #architecture #security #distributed

## [.NET 11 Preview 7 is now available!](https://devblogs.microsoft.com/dotnet/dotnet-11-preview-7/) 🤓

Runtime Async V2 replaces compiler-emitted state-machine classes with runtime-managed suspension: the JIT now compiles a dedicated runtime-async version of every synchronous task-returning method, continuations opt out of ExecutionContext capture when no ambient state is in use, and tail-merged suspension points reduce generated code size. Simultaneously, the x86/x64 hardware baseline moves to x86-64-v3 — AVX2, FMA, and MOVBE are now assumed universally present — and Arm64 requires LSE atomics, letting the JIT drop per-call feature-detection paths that previously ran on every hot path; a faster Math.BigMul now emits a single MUL instruction on x64 instead of a multi-step sequence. Two new architectures (RISC-V and s390x) are enabled in this preview, and Runtime Async no longer requires EnablePreviewFeatures for projects targeting net11.0. Final release is targeted for November 10, 2026. #softwareengineering #engineering #quality #development

## [Introducing AI dashboard and workflow generation in ClickStack](https://clickhouse.com/blog/clickstack-ai-dashboard-generation) 👨‍💼

Rather than prompting an LLM to generate a finished visualization in one shot, ClickStack's new AI dashboard feature sends the model through an investigation phase first — using the same MCP tool interface exposed to Claude, Cursor, and Codex — so it understands the actual schema, query patterns, and cardinalities before writing a single SQL expression. The MCP-first design means the AI agent's investigation is the same API surface an external coding agent would call, creating a unified tool layer shared between ClickStack's built-in AI and any MCP-compatible external tool; a workflow started in ClickStack can be refined in Cursor without format conversion. Teams can generate full service-health, latency-by-endpoint, or error-grouped dashboards from a single natural language prompt. #devops #ai #engineering #softwareengineering
