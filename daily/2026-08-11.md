## [Session revocations at scale](https://www.canva.dev/blog/engineering/session-revocations-at-scale/) 👨‍💼

Canva's redesigned session revocation system eliminates networked database lookups from the hot authentication path by using Amazon S3 as the durable revocation store and distributing compact, in-memory indexes to application gateways. The new binary index format cut the per-gateway revocation cache memory footprint by 87.5% compared to the previous approach, while also reducing read-replica infrastructure and improving deployment speed. The key insight is architectural: keep the authoritative revocation record on a durable blob store, then push a lightweight derivation of that data close to where auth decisions are made, rather than reaching back to a database for every session check across hundreds of millions of active sessions. #architecture #cloud #security #softwareengineering

## [CosmosEscape: Taking Over Every Azure Cosmos DB](https://www.wiz.io/blog/cosmosescape-taking-over-every-database-in-azure-cosmos-db) 🤓

Wiz Research chained a Gremlin sandbox escape into a platform-wide credential theft: Cosmos DB compiled Gremlin queries into .NET code under restrictions that failed to account for reflection, allowing code execution on the shared DB Gateway and extraction of a master key that granted full read and write access to any Cosmos DB account on the service — including databases backing Microsoft's own Entra ID, Teams, and Copilot. The only prerequisite was a standard Azure subscription with a Gremlin database, obtainable in minutes with no elevated privileges. Microsoft deployed a hotfix within 48 hours of the November 2025 disclosure that blocked the Gremlin entry point, but eliminating the platform-wide credential model and rolling out per-account isolation across all regions took until July 2026. The exploit was presented publicly at Black Hat USA on August 6, 2026. #cloud #db #security #architecture

## [Introducing Meerkat: an experiment in global consensus](https://blog.cloudflare.com/meerkat-introduction/) 🤓

Cloudflare built Meerkat, an internal control-plane service for globally consistent coordination, on QuePaxa — a 2023 consensus algorithm by Tennage & Băsescu that allows all replicas to accept writes simultaneously, removing the leader-timeout availability loss that affects Raft-based systems in wide-area deployments. Unlike Raft, where a follower must wait out a leader lease before initiating an election, QuePaxa progress is never halted by timeouts, making it well suited for Cloudflare's 300-plus PoP topology where a "leader" may be unreachable to half the network at any moment. Meerkat's current scope is intentionally narrow — routing low-volume but high-stakes control-plane metadata like database leadership grants and AI model placement decisions — but Cloudflare claims this will be the first industrial deployment of QuePaxa at global scale once it reaches production. #distributed #architecture #engineering
