## [The Hard-Stop Rule: From 3 HCM Monoliths to 120 Domain Microservices](https://www.infoq.com/articles/pull-based-migration/) 👨‍💼

A pull-based migration strategy called the Hard-Stop Rule forbids any ticket from touching the monolith — every new feature must carve out a new domain service instead, making migration a side effect of normal product work rather than a parallel workstream. The overhead is real (~4–6 hours per story, roughly 50% of story time), but three platform investments — self-service provisioning in minutes, an API gateway as routing seam, and a cached feature-flag layer for gradual rollout — made the overhead tolerable over five years. The result: 120+ microservices running on Azure with zero downtime and no dedicated migration budget; the original three monoliths still handle untouched code paths. #architecture #migration #softwareengineering #engineering

## [From Prototype to Production: High QPS for Databricks AI Search](https://www.databricks.com/blog/prototype-production-high-qps-databricks-ai-search) 👨‍💼

Databricks AI Search High QPS is now GA for standard endpoints, addressing the gap between prototype-grade vector search (single-digit QPS) and production workloads like real-time search bars, recommendation engines, and entity matching that need 100–1000+ QPS. Default endpoints scale to 20–200 QPS depending on index size; exceeding that requires setting a single `target_qps` parameter with no replica management or load balancer configuration. Built-in observability surfaces endpoint QPS, latency, and health directly in the UI. #ai #db #engineering

## [Stop switching tools to find answers: Grafana Assistant now works across 30+ data sources](https://grafana.com/blog/stop-switching-tools-to-find-answers-grafana-assistant-now-works-across-30-data-sources/) 👨‍💼

Grafana shipped six AI observability tools to GA simultaneously as part of Grafana AI Week (July 27–31): Grafana Assistant Investigations, Workspace, Automations, a Cloud MCP server (single URL exposing Grafana Cloud to any MCP-compatible agent), gcx CLI (auto-detected by Claude Code, Copilot, and Cursor), and Agent Observability. The unified interface now queries 30+ data sources via natural language — Snowflake, Oracle, Elasticsearch, Dynatrace, Honeycomb, MongoDB, Zabbix, Jira — eliminating context switching during production incident investigations. The timing is deliberate: 92% of practitioners want AI catching anomalies, but only 57% have AI observability for their own AI systems. #devops #ai #engineering
