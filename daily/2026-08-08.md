## [Unifying Workers AI and AI Gateway into a single AI control plane](https://blog.cloudflare.com/workers-ai-gateway-unification/) 👨‍💼

Two previously separate Cloudflare products — Workers AI (managed GPU inference) and AI Gateway (model routing and observability control plane) — are now a single endpoint. Any provider, including Cloudflare's own GPUs, Anthropic, OpenAI, or Google, routes through one API with observability, caching, rate-limiting, and security applied once at the gateway layer rather than per-provider. Prepaid credits now work across all providers through a unified wallet, ending the bookkeeping tax of managing separate budgets per inference vendor; model-first bindings let applications declare target models and have failover and provider selection resolved by the control plane rather than in application code. #cloud #ai #engineering #devops

## [Unlocking the future of shared storage: Filestore on Colossus](https://cloud.google.com/blog/products/storage-data-transfer/filestore-file-service-runs-on-colossus) 🤓

Google migrated Filestore off VM-based storage clusters onto Colossus — the distributed storage substrate also running YouTube, Gmail, and Gemini — and the key architectural unlock is IOPS decoupled from capacity. Teams can now right-size performance and storage independently, eliminating the over-provisioning penalty that previously forced capacity purchases to meet latency targets. Filestore multishares drop the minimum per-container allocation to 10 GiB, and NFS file locking on Colossus supports high-concurrency AI agent workloads where hundreds of agents read and write shared state simultaneously without consistency failures. #cloud #distributed #architecture #engineering

## [How we migrated a live routing system using AI-assisted refactoring](https://www.datadoghq.com/blog/engineering/ai-assisted-storage-migration/) 👨‍💼

Datadog replaced FoundationDB with PostgreSQL plus DuckDB in their Stream Router — the live system routing all metric production traffic — cutting a 45-minute operation to one second (roughly 2,700×) while reducing database costs 90% and dataset size 40×. The FoundationDB key-value model forced thousands of sequential reads per operation requiring in-app relationship reconstruction; a relational schema with database-enforced foreign keys collapsed those into single SQL queries. The team used Claude to generate structural documentation of the existing codebase and ran AI-assisted method-by-method refactoring against failing end-to-end tests, then validated through parallel blue/green deployment before cutover — achieving zero incidents across a migration that took 3 months from design to production. #engineering #db #migration #ai
