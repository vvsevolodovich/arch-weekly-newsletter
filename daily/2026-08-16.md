## [How Cloudflare detects MCP traffic and helps secure it](https://blog.cloudflare.com/mcp-security-updates/) 🤓

As MCP adoption grows inside enterprise networks, Cloudflare Gateway now answers the question "is this MCP?" at the protocol layer rather than relying solely on URL allowlists: detection combines hostname/path heuristics (known server domains like `mcp.stripe.com`, wildcard `mcp.*` patterns, paths `/mcp` and `/mcp/sse`), DLP-based body inspection using regex against JSON-RPC method fields (`tools/call`, `prompts/get`, `initialize`), and a new `experimental.is_mcp` selector in HTTP policies that triggers on the MCP-Protocol-Version header mandated by the 2025-11-25 spec and extended to every POST by the 2026-07-28 spec. The practical output is a security team's ability to surface shadow MCP traffic—agents calling unauthorized remote MCP servers—and enforce portal-only access or hard-block direct connections on managed network paths without touching the MCP servers themselves. #security #architecture #ai #engineering

## [How We're Building Scam Alert on WhatsApp With End-to-End Encryption and Verifiability Guarantees](https://engineering.fb.com/2026/08/12/security/how-were-building-scam-alert-whatsapp/) 🤓

WhatsApp's Scam Alert is a structurally novel approach to client-side AI safety: a lightweight ML model downloads to the user device and classifies incoming messages from non-contacts by analyzing conversational structure and linguistic patterns, with zero message content leaving the device for inference. The minimal telemetry needed to measure feature efficacy travels through a confidential federated analytics pipeline built on confidential VMs (a form of TEE), delivered to WhatsApp as differentially private aggregates rather than raw signal. Every architectural claim is made independently verifiable: model weights are published, manifests are signed by Cloudflare's transparency infrastructure, a third-party ledger records all model updates, and users can inspect an in-app audit log—a complete verifiability stack that security researchers can probe through an expanded bug bounty. #security #ai #architecture #engineering

## [How Wiz Secures Personal Repos in the Software Supply Chain](https://www.wiz.io/blog/securing-personal-repositories) 👨‍💼

Wiz Research found verified secret leaks in 65% of the Forbes AI 50, with 56% of company-impacting secrets residing not in enterprise repositories but in employees' personal GitHub accounts—outside the reach of most corporate secret-scanning programs. The attack surface is structural: engineers who push to a GitHub Enterprise org by day maintain side projects under personal accounts, and when corporate code or credentials are accidentally copied there, AI-assisted development accelerates the spread because it increases code reuse and automated change propagation faster than manual review can catch. Wiz's solution correlates personal repos to corporate developer identities, validates the actual risk of each exposed secret, and routes remediation back to the owning developer rather than the security team. #security #devops #engineering #softwareengineering
