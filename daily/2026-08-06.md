## [Behind the scenes: How we build, test, and scale Google Agent Skills](https://cloud.google.com/blog/topics/developers-practitioners/behind-the-scenes-how-we-build-test-and-scale-google-agent-skills) 👨‍💼

Google's agent skill engineering model treats skills as living products rather than snippets: each has a standardized repo layout, automated CI with linters and link checkers, AI-assisted validation at commit time, and a 2×2 eval matrix measuring both accuracy (task completion rate) and efficiency (token consumption, completion time). The ops model favors remote MCP tools over CLI/API calls for reliability, with on-submit evals catching regressions immediately and weekly scheduled quality checks preventing drift. Governance separates repo maintainers from skill owners, enabling autonomous ownership at scale. #ai #softwareengineering #engineering #quality

## [What's new in AI infrastructure and orchestration](https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month) 👨‍💼

Google Cloud's July 2026 AI infra roundup spans three GA milestones: C4N VMs deliver 400 Gbps networking and 95M PPS for network-intensive workloads; GKE Dataplane V2 now scales to 15,000 nodes with active Network Policy enforcement; Managed Lustre ships in four throughput tiers (125/250/500/1000 MB/s per TiB, up to 8 PB). On the training efficiency side, llm-d cooperative time-slicing interleaves RL jobs and lifts accelerator duty cycles from roughly 40% to 70% with no impact on model convergence. k8s-aibom rounds it out by generating CycloneDX ML-BOMs from Kubernetes, bringing AI supply chain security inline with existing SBOM toolchains. #cloud #devops #ai #architecture #engineering

## [What's new in Gemini Enterprise Agent Platform](https://cloud.google.com/blog/products/ai-machine-learning/whats-new-in-gemini-enterprise-agent-platform) 👨‍💼

Google's Gemini Enterprise Agent Platform adds five production-grade primitives in one release: Agent Runtime supports complex multi-day agents running continuously for up to 7 days; Agent Memory Bank provides low-latency personalization by extracting structured conversation context; Agent Identity introduces a native IAM type on open standards with least-privilege enforcement and non-repudiable auditing; Agent Gateway acts as a central control plane with IAM conditions, natural-language rules, and Model Armor for prompt injection and data leakage protection. Together these primitives convert one-shot agents into auditable, long-lived services — the infrastructure gap that has blocked enterprise adoption more than model capability. #ai #cloud #architecture #engineering
