## [MCP 2026-07-28 Release Candidate: Stateless Core, Multi-Round-Trip, and Authorization Hardening](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) 🤓

Running at close to half a billion SDK downloads per month, the Model Context Protocol's 2026-07-28 release candidate drops the session-based architecture entirely — the `initialize` handshake and `Mcp-Session-Id` header are gone, so any server instance handles any request without sticky routing, shared session stores, or deep-packet inspection at the load balancer. Server-initiated user prompts move from persistent SSE streams to an `InputRequiredResult` / retry pattern where clients re-submit the original call with answers embedded, preserving statelessness end-to-end; the Streamable HTTP transport now mandates `Mcp-Method` and `Mcp-Name` headers so gateways can route on operation type without body inspection. Six Security Enhancement Proposals harden OAuth/OIDC alignment (RFC 9207 `iss` validation, mandatory `application_type`, proper refresh-token revocation), and a formal 12-month deprecation window governs future removals — signalling that a protocol now at production scale is engineering for long-term operational maturity. #architecture #ai #distributed #engineering

## [Six Agent Harness Capabilities for Higher Model Performance](https://developer.nvidia.com/blog/six-agent-harness-capabilities-for-higher-model-performance/) 🤓

The agent harness — how it renders context, executes actions, manages state, and terminates tasks — can swing benchmark scores by double digits independently of the underlying model. NVIDIA's open-source NOOA framework structures agents as single Python classes where capabilities, state, and prompts map to methods, fields, and docstrings with type annotations as enforced contracts; long-term relational memory persists in a typed, human-readable SQLite store, eliminating context-compaction pipelines entirely. Across SWE-bench Verified, CyberGym L1, and ARC-AGI-3, NOOA reaches state-of-the-art accuracy at lower token cost than prior harnesses; the research augmentation variant solved 86.8% of ARC-AGI-3 tasks using a commodity model with no network access. NVIDIA is open-sourcing weights, data, and the harness code via the Open Secure AI Alliance, making harness-level ablation a first-class engineering practice. #ai #engineering #softwareengineering #architecture

## [We're Open Sourcing Our Privacy Proxy CLI](https://blog.cloudflare.com/open-sourcing-our-privacy-proxy-cli/) 👨‍💼

Testing split-trust privacy infrastructure — where no single party sees both the client identity and the request content — has historically required protocol expertise and custom tooling that only large organizations could build. Cloudflare distilled operational experience running Oblivious HTTP at millions of requests per second into pvcli, a curl-like CLI that unifies OHTTP, CONNECT proxying, MASQUE (TCP-over-HTTP/3, UDP-over-HTTP/2 and HTTP/3), and Privacy Pass in a single tool, released under Apache 2.0. The same protocols underpin Apple's iCloud Private Relay, Microsoft's Bing privacy proxy, and AI agent pipelines that must guarantee neither the relay nor the origin sees both user identity and query — making pvcli the first open debugger purpose-built for this trust-split architecture. #security #engineering #cloud #architecture
