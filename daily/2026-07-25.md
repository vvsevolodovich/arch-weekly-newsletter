## [Certighost (CVE-2026-54121): AD CS Domain Takeover via Chase Exploitation](https://gist.github.com/H0j3n/a5ef2609b5f2944ac2390a191a534c26) 🤓

A low-privileged domain user achieves full Active Directory forest compromise by exploiting the CA's "chase" fallback in directory-object resolution: supplying crafted `cdc` and `rmd` certificate request attributes directs the CA to query an attacker-controlled host, which returns forged `ObjectSID` and `dNSHostName` values accepted without verification. The forged DC certificate enables a DCSync attack extracting the `krbtgt` secret and every forest credential. Microsoft's July 14 patch adds `_ValidateChaseTargetIsDC`, enforcing an AD lookup for the `SERVER_TRUST_ACCOUNT` flag (0x2000) before following any chase target — a validation gate the original CA implementation entirely lacked. PoC published July 24 by H0j3n and Aniq Fakhrul; affects Windows Server 2012–2025, CVSS 8.8. #security #engineering #architecture

## [BGP ORIGIN attribute manipulation and its impact on the Internet](https://blog.cloudflare.com/bgp-origin-attribute/) 🤓

Cloudflare's analysis of the global routing table finds that nearly 70% of BGP paths have had their ORIGIN attribute rewritten by transit providers — a practice James Bensley first documented at RIPE 91 that turns out to be endemic at scale. Providers rewrite ORIGIN from INCOMPLETE or EGP to IGP because the BGP best-path algorithm treats IGP as the most preferred value, steering traffic toward the manipulating AS and increasing its revenue; the reverse (rewriting to EGP or INCOMPLETE) deprioritizes competitor routes. The ORIGIN attribute carries no cryptographic signature, making this manipulation structurally invisible to the receiving network and leaving route selection as a revenue-driven arms race with no standard enforcement mechanism. #distributed #architecture #engineering
