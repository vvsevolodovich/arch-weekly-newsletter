## [GEM Training: How Meta Doubled the Efficiency of Its LLM-Scale Ads Foundation Model](https://engineering.fb.com/2026/08/03/ml-applications/training-gem-at-llm-scale-meta-ads-recommendation-foundation-model/) 🤓

Meta's GEM is the first ads recommendation foundation model trained at LLM scale — achieving 20–25% Model FLOPs Utilization and a 23× increase in effective training throughput while training on 16× more GPUs, requiring hardware/software co-design of kernels, precision, parallelism, networking, and memory. The core challenge is that today's GPUs are optimized for dense-attention LLM workloads, not recommendation systems with sparse, heterogeneous inputs, so GEM demanded custom GPU kernels and hybrid parallelism strategies unavailable off the shelf. Since launch, GEM has driven a 5% increase in ad conversions on Instagram and 3% on Facebook Feed, and teaches the rest of the ads ranking stack through knowledge distillation — making it a blueprint for applying LLM-scale training discipline to non-language recommender systems. #ai #llm #architecture #engineering

## [How Cloudflare Enforces Engineering Standards Using AI](https://blog.cloudflare.com/engineering-standards-enforcement/) 👨‍💼

Rather than a single monolithic review prompt, Cloudflare deploys up to seven specialized AI reviewers — covering security, performance, code quality, documentation, release management, and compliance with their internal "Codex," a governed body of engineering standards that agents consume across the SDLC. Since May 2026, the system has flagged nearly 250,000 deviations and blocked 16,000 merges; a companion incident-report reviewer has assessed over 200 postmortems, surfacing missing detection signals, incomplete timelines, and absent follow-up action items. The whole stack runs as a Cloudflare Worker backed by D1, AI Gateway, and a Cron Trigger — making the architecture itself a demonstration of the platform it enforces. #quality #engineering #ai #softwareengineering

## [Turn One Giant AI-Generated Pull Request to a Reviewable Stack](https://github.blog/engineering/turn-one-giant-ai-generated-pull-request-to-a-reviewable-stack/) 👨‍💼

Coding agents left to their own devices open one giant, unreviable pull request — GitHub's stacked PR support (in public preview since July 2026) and the `gh stack` CLI give the structural fix by teaching agents to commit logically coherent slices that form an ordered, dependent stack. Each slice can be reviewed and merged independently, keeping human reviewers in the loop as AI-assisted output volume scales; the technique requires prompting agents to decompose work before committing rather than retrofitting structure after the fact. With stacked PRs now a first-class GitHub primitive, the bottleneck on AI-assisted development shifts from generation throughput to review throughput — and this post addresses exactly that. #engineering #development #softwareengineering #ai
